## 2. 算定基礎届（定時決定） … ★作っていない★

| | |
|---|---|

| 期限 | **毎年 7月10日まで**（10日が土日なら 翌営業日） |

## 3. 月額変更届（随時改定） … ★該当判定だけ 在る／届は 作っていない★

| | |
|---|---|
| 正式名 | 被保険者報酬月額変更届 |
| 出す先 | **日本年金機構** |
| 期限 | **該当したら すみやかに**（定時の期限は 無い） |
| 3つとも 揃った時だけ | ① **固定的賃金の変動**（昇給・降給・給与体系変更・手当の追加/変更）<br>② 変動月以後 **引き続く3か月の平均**で **2等級以上の差**<br>③ その3か月とも **支払基礎日数 17日以上**（特定適用事業所の短時間労働者は **11日**） |
| いつから | 変更後の報酬を **初めて受けた月から 4か月目**（例：4月に変動 → **7月から**） |
| 算定基礎届との関係 | **7〜9月の随時改定が 優先**。算定基礎届を出した後でも 該当したら 月額変更届を 出す |
| 出典 | 日本年金機構「随時改定（月額変更届）」<br>https://www.nenkin.go.jp/service/kounen/hokenryo/hoshu/20150515-02.html<br>同 FAQ（どちらが優先か） https://www.nenkin.go.jp/section/faq/kounen/hyoujunhoushu/hyoujyunhousyuu05.html |
| うちの状態 | ★該当の判定は 在る★（`kyuyo/js/app.js` 1199行あたり「随時改定(月額変更届)の該当判定」）。**届は 作っていない** |

## 4. 労働保険 年度更新（申告書） … ★作っていない★

| | |
|---|---|
| 正式名 | 労働保険 概算・確定保険料／石綿健康被害救済法 一般拠出金 申告書 |
| 出す先 | **金融機関 ／ 都道府県労働局 ／ 労働基準監督署** |

| うちの状態 | ★雇用保険の率は 単一ソースで 持っている★（`kyuyo/lib/koyo-hoken.js`・**労働保険年度は 4月切替**）。**申告書は 作っていない** |

## ★次に作る時の順番（材料が 揃っている順）★

1. **月額変更届** … ★判定が もう在る★＝あとは 届の中身を 組むだけ
2. **算定基礎届** … 4〜6月の報酬は 月次から 出せる（保存済みの月次を 使う）
3. **労働保険 申告書** … 賃金総額の 年度集計が 要る（賃金台帳から 出せる）

★どれも 様式（レイアウト）は 公式の物に 合わせる★。**うちの実物は「正」ではなく「1例」**
（[[feedback_sample_is_not_the_standard]]）。
