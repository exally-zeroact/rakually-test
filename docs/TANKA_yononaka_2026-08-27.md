## A 法律 — ★単価は 必須ではありません★

### 出典1 国税庁 タックスアンサー No.6625「適格請求書等の記載事項」
- URL <https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6625.htm>
- ページの表記 **「令和7年4月1日現在法令等」** ／ **確かめた日 2026-08-27**
- 記載しなければならない事項（原文）

  | # | 記載事項 |
  |---|---|
  | ① | 書類作成者の氏名または名称および登録番号 |
  | ② | 取引年月日 |
  | ③ | 取引内容（軽減税率の対象品目である旨） |
  | ④ | 税率ごとに区分して合計した税込対価（又は税抜対価）の額及び適用税率 |
  | ⑤ | 税率ごとに区分した消費税額等 |
  | ⑥ | 書類の交付を受ける事業者の氏名または名称 |

- ⇒ **「単価」「数量」は 1度も出てきません**

### 出典2 国税庁「インボイス制度の理解のために」（令和8年4月）
- URL <https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/pdf/0020006-027.pdf>
- 原文 **「様式は、法令又は通達等で定められておらず、必要な事項が記載されたものであれば、名称を問わず、また、手書きであっても、適格請求書に該当します。」**
- **同じPDFの「適格請求書の記載事項」の見本** … 明細の列は **「日付／品名／金額」の3列だけ**
  （11/1 魚＊ 5,000円 ／ 11/1 豚肉＊ 10,000円 ／ 11/2 タオルセット 2,000円）
  ⇒ **国税庁の見本そのものに 単価・数量の列が ありません**
- ※ 同じPDFの**端数処理の説明**（8ページ）には「取引年月日 品名 **数量 単価** 税抜金額 消費税額」の例も出ます
  ＝ **見本は2通り出てくる**（＝どちらでもよい、の裏付け）

**★答え … 単価は 法律で必須ではない＝焼き付ける理由が無い★**

## B 世の中 — 8本（出典URLつき）

| マネーフォワード クラウド請求書 | 在る | **確かめられなかった**（単位の表示/非表示は在る） | <https://biz.moneyforward.com/support/invoice/guide/document02/do13.html> |
| board | 在る | **確かめられなかった**（金額まるごと非表示は在る） | <https://the-board.jp/helps/help_document_settings/> |

> ### ★「確かめられなかった」は「出来ない」ではありません★
> マネーフォワード クラウド請求書 ／ board ／ MakeLeaps の「消せるか」は、
> **公式ヘルプに その記載を見つけられなかった**という意味です。
> **出来ない と読まないでください。**（指示役 2026-08-27）

**★多いのはどちらか（1行）★
どのソフトも「既定は 単価あり」。ただし 消せる／選べる事が確かめられたのは 3本（Misoca・freee請求書・楽楽明細）。**
