## 1 今どうなっているか（実測）

**振込指定日は「会社の設定」に置いた 日付の欄が1つだけ**（`kyuyo/js/app.js:3236` `data-fc="furiDate"`）。
対象月を変えても **この欄は そのまま**。全銀の取組日は ここから作る（`app.js:3301`）。

| 振込指定日の欄 | 銀行へ行く全銀ヘッダーの**取組日** | 何が起きるか |
|---|---|---|
| **空のまま** | **`0000`** | **在りえない日付が銀行へ行く**。画面は何も言わない |
| **先月のまま** `2026-08-25` | **`0825`** | **先月の日付で振込を出す** |
| その月 `2026-09-25` | `0925` | 正しい（**毎月 人が入れ直した時だけ**） |

`0000` になる理由＝`zengin.js:47` の `padN('',4)`＝**空を 0 と読んで 4桁に詰める**。
**止める所が どこにも無い**（`Zengin.build` は取組日を見ない）。

**★一方で、正しい日は アプリがもう計算できている★**（`kyuyo/lib/payroll-monthly.js:308 payDateObj`）

| 対象月 | 会社の決まり | 出る支給日 |
|---|---|---|
| 2026-09 | 毎月25日・翌月払い | **2026-10-25** |
| 2026-09 | 毎月**末日**・翌月払い | **2026-10-31** |
| 2026-09 | 毎月25日・当月払い | 2026-09-25 |
| **2026-12** | 毎月25日・翌月払い | **2027-01-25**（年をまたぐ） |

⇒ **持っている物を使っていないだけ**。ここが直しの芯。

## 2 直し方

| | 案A（**私の推し**） | 案B | 案C |
|---|---|---|---|
| 欄 | **「振込指定日」の入力欄をやめる**。その月の**支給日を出して見せる** | 欄は残し、対象月を変えたら**自動で入れ直す** | 今のまま。**空なら止める**だけ |
| 直る物 | 空も 先月のままも 両方 | 空も 先月のままも 両方 | **空だけ**（先月のままは残る） |
| 残る穴 | 無し | **人が上書きした古い日が また残る**（同じ事故が戻る） | **先月の日付が銀行へ行くのは そのまま** |

**推す理由（案A）**
- **「聞いてあげる。埋めさせない。」**（全アプリの決まり）＝ 空欄を出して人に入れさせない。
  **当てて、根拠を見せて、違う時だけ直させる**。
- **同じ状態を2か所で別々に持たない**。今は「明細に出る支給日」と「銀行へ出す取組日」が
  **別々の出どころ**なので、**紙は10/25・銀行は08/25** という食い違いが作れてしまう。
  案Aは **出どころを1つ**にする（`payDateObj`）。
- 「その月だけ違う日にしたい」（銀行の都合・年末年始）は**在る**ので、
  **[この月だけ変える]** を置く。ただし **その月に紐づけて持つ**＝翌月には持ち越さない。

**案Aの画面（言葉は仮）**
```
振込指定日   2026年10月25日（土）→ ★2026年10月23日（金）★
             会社の決まり「毎月25日・翌月払い」から出しました。
```

## 3 土日・祝日をどうするか（**ここは決めてほしい**）

- 銀行は **土日祝に振込できない**。支給日がそこに当たった時、**前倒しか 後ろ倒しか**は
  **法律で決まっていません**（労基法24条は「一定の期日」までで、ズラす向きは**就業規則が決める**）。
  ⇒ **焼き付けてよい型ではない** ので、**会社の設定**にします。
- **既定は「前の営業日」**（世間の給与でいちばん多い形）。**後ろ倒しも選べる**ようにする。
- 祝日は **`kyuyo/lib/holidays.js` が既に持っています**（国民の祝日に関する法律から自前計算・
  ハッピーマンデー・春分秋分・振替休日・国民の休日つき）。**新しい表は作りません**。
- **年末年始（12/31〜1/3）は 祝日ではない**が 銀行は休みです。ここは
  **「銀行の休み」として別に持つ**しかありません（法律ではなく 全銀の申し合わせ）。
  ⇒ **★指示役に確認したい所★**：この4日を 焼き付けてよいか（＝毎年 変わらない物として持つか）。

## 4 出させない・見せない

- **取組日が作れない時は 全銀ファイルを作らせない**（押せなくして **理由を出す**）。
  ＝**`0000` を銀行へ出さない**。今は黙って出ます。
- 見張りを1本 足す：**`Zengin.build` に 取組日が MMDD の4桁で無い物を渡したら 赤**。
  （`padN` が 空を 0 に読む所は **他の欄（金額・口座）でも同じ事が起きる**ので、
   **取組日だけ** 別に見る＝ここは日付であって 数ではない）

---

## 5 明細の支給日と 必ず同じにする

`kyuyo/js/app.js:2909` の `payDateForSlip()` と 全銀の取組日を **同じ関数から出す**。
＝**紙に「10月25日」と刷って 銀行に「0825」を送る** が **作れなくなる**。
見張り：**同じ月で 紙の支給日と 全銀の取組日が 1日でも違ったら 赤**。
