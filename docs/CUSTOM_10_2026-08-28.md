## 決め方（指示役 2026-08-27 の決め方）

```
 ★法律で必須★         → 全部の様式に入れる（焼き付ける）
 ★必須でない＋世の中で多い★ → 既定は「在る」／消せる
 ★必須でない＋世の中で少ない★ → 既定は「無い」／足せる
 ⇒ ★どちらでも 相手ごと・会社ごとに 選べる★
```

## 守っている事（機械で固定）

- **選んでも 金額は1円も変わらない** … `koujo-paper.test.mjs`「★選んでも 金額は1円も変わらない★」
  （既定と 全部変えた時で、締めの数が**完全に同じ**である事を突き合わせ）
- **何も選ばなければ 今までどおり** … 空の値は**保存しない**（様式の既定が効く）
- **順番** … ①その1通が持つ物 → ②会社が決めた物 → ③様式の既定

## 欠け

- **敬称の自動判定（会社か人か）は まだ当てていません**（今は相手ごとに手で選ぶ）
- **対象期間を 締め期間から当てる**のは 次回（`lib/kikan.js` を見てから）
- **実機（webkit）で 375／390／430 は これから見ます**
