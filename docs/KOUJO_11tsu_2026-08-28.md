## 分かった事

### ★型は2つ。違うのは「並び」と「¥記号」だけで、計算は同じ★

| | 型A（4通） | 型B（7通） |
|---|---|---|
| 並び | 工事代金 → **小計（税抜）** → 消費税 → 合計（税込） | 工事代金 → 消費税 → **小計（税込）** |
| ¥記号 | **付く**（¥258,400） | **付かない**（294,690） |
| 控除の合計の呼び名 | **小計** | **中計** |
| 計算 | **外税・税抜×10%** | **外税・税抜×10%**（同じ） |

⇒ **「小計」という同じ言葉が、型Aでは税抜・型Bでは税込を指しています**
（＝**呼び名を焼き付けてはいけない**という裏付けが、さらに強くなりました）

### ★★訂正します（08-26 の私の報告が間違っていました）★★

08-26 の「実物の請求書は何が違うのか」の表で、私は八木工業を
**「内税表示（小計＝税込・消費税＝内税）」** と書きました。**これは誤りです。**

- 実測 … 267,900 × 10% = 26,790 ／ 267,900 + 26,790 = 294,690 ＝**外税**
- 内税に見えた理由 … 294,690 × 10/110 も 26,790 になるため、**どちらでも同じ数**になる
- ⇒ **正しくは 外税**。**11通とも 外税**です。

**あわせて 端数の型も 訂正します**
- 08-26 の表では 控除型11通を「③控除型（内税 or 税抜＋控除）」と **別の型** に数えました
- 実測では **11通とも ①税抜・切り捨てと 同じ計算** です
- ⇒ 端数の型は **①39通（28＋11）／②税込から逆算 7通／④値引きに税なし 1通（保留）** が正しい
