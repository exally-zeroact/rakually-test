### 項番28 配偶者の「性別（続柄）」＝**中身は 続柄**

`1 夫` / `2 妻` / `3 夫（未届）` / `4 妻（未届）`

### 職業と 理由は 配偶者と その他で **別物**

| | 配偶者 | その他の被扶養者 |
|---|---|---|
| 職業 | 項番48 … 1無職 / 2パート / 3年金受給者 / **4その他**（4つ） | 項番92 … 1無職 / 2パート / 3年金受給者 / 4小・中学生以下 / 5高・大学生 / **6その他**（6つ） |
| になった理由 | 項番46 … 1配偶者の就職 / 2婚姻 / 3離職 / 4収入減少 / 5その他 | 項番95 … **1出生** / 2離職 / 3収入減 / **4同居** / 5その他 |

→ **配偶者の欄を その他へ 使い回すと 全部 ずれる。**

### 「必ず 空」の 2つ

| 項番 | 項目 | 原文 |
|---|---|---|
| 70 / 103 | 被扶養者番号 | 種別「－」・文字数「０」・**省略する** |
| 136 | 届出意思確認済 | 種別「－」・文字数「０」・**省略する** |

### 郵便番号・住所は **同居でも 省略できない**

- 項番37/38/39（配偶者）… 「配偶者である被扶養者を設定する場合は省略不可とする。
  **※被扶養者の個人番号の有無、同居・別居の別の区分の設定に関わらず、省略不可とする**」
- 項番80/81/82（その他）… 「異動の別が該当『1』、非該当『2』の場合、かつ
  その他の被扶養者を設定する場合は省略不可とする。**※同上**」

→ 画面の 郵便番号・住所に「別居のとき」と 書いていたのは **間違い**（2026-09-08 に 直した）。

### 個人番号を 持たない うちの 道

うちは **マイナンバーを お預かりしない**（持たない物は 漏れない）。原文の 相関は：

- 項番15 基礎年金番号（課所符号）…「**個人番号が空欄の場合省略不可**」
- 項番18/19/20 被保険者の 郵便番号・住所 …「**個人番号を入力した場合は省略する**」
  → 裏を返すと 個人番号が 空なら **出す**

⇒ うちは **基礎年金番号＋郵便番号＋住所** で 出す。
（司さん 2026-09-05「競合がやりよることはやれ」＝基礎年金番号を お預かりする 決め）

## 文字数と バイト数

原文は 漢字を「文字数」、英数カナを「バイト数」で 書く。
同じ欄の 2つの 上限が **いつも ちょうど 2倍**（例：漢字0〜24 ／ 数字英字カナ0〜48）。
⇒ 見張りの 中では **バイトで 数えて よい**（資格喪失届の 見張りと 同じ 測り方）。

| 欄 | 原文 | 見張りの 上限（バイト） |
|---|---|---|
| 氏名（カナ） | 0〜25 | 25 |
| 氏名（漢字） | 0〜12文字 | 24 |
| 住所（漢字） | 0〜37文字 | 74 |
| 備考 | 漢字0〜37 ／ カナ0〜75 | 75 |
| その他の理由 | 漢字0〜24 ／ カナ0〜48 | 48 |
| 続柄コードその他補足 | 漢字0〜12 ／ カナ0〜24 | 24 |
| 外国籍 | 0〜30文字 | 60 |
